第5章查数据 SELECT

🔍 SELECT 是什么？

SELECT 是最最常用的命令，用来查看表里的数据。

📌 查出所有数据

-- 查出所有数据（* 表示所有列）
SELECT * FROM dinosaurs;

结果：

idnametypeage
1霸王龙肉食恐龙25
2三角龙草食恐龙20
3翼龙飞行恐龙15

📌 只查某几列

-- 只看名字和种类，不看年龄
SELECT name, type FROM dinosaurs;
nametype
霸王龙肉食恐龙
三角龙草食恐龙
翼龙飞行恐龙

SELECT * = 打开整张纸看

SELECT name, type = 只看名字和种类那两列，像用手指遮住其他列

🔍 SELECT * FROM 表名 = 查出所有数据
