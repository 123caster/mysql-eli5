第4章SQL 语言

💬 SQL 是什么？

我们想对数据库做事情（查数据、加数据、改数据、删数据），就需要用一种「语言」来告诉 MySQL。

SQL（Structured Query Language，发音是 "S-Q-L"）

它就是和 MySQL 说话的语言！

📝 SQL 的四个基本动词

🔍
SELECT
查数据（看有什么）
➕
INSERT
加数据（添加新的）
✏️
UPDATE
改数据（修改旧的）
🗑️
DELETE
删数据（不要了）
🔍 SELECT = 看 | ➕ INSERT = 加 | ✏️ UPDATE = 改 | 🗑️ DELETE = 删
🔍 ➕ ✏️ 🗑️
