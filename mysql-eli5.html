1. 什么是数据库？ 概念

📖 小明的故事

小明喜欢收集恐龙玩具。他把每只恐龙的名字、年龄、种类写在纸上。

后来恐龙太多了，纸张乱糟糟的，找不到想找的那只。

于是小明买了一个整理箱，给每只恐龙一个固定的位置，还做了标签。

现在找恐龙超方便！🎉

🤔 数据库就像...

一个超大超智能的整理箱！它可以：

  • 📦 存放超多数据（几百万条都没问题）

数据库 = 存数据的「大仓库」

3. 表 - 数据的家 核心

在 MySQL 里，数据都放在表（Table）里。

📊 表是什么？

想象一下Excel 表格！

  • 有行（横着的一条一条）
  • 有列（竖着的一栏一栏）

比如我们创建一个「恐龙表」：

id（编号） name（名字） type（种类） age（年龄）
1 霸王龙 肉食恐龙 25
2 三角龙 草食恐龙 20
3 翼龙 飞行恐龙 15
📝 解释一下
  • 每一行 = 一只恐龙的信息
  • 每一列 = 恐龙的一个特点（名字、种类、年龄...）
  • id = 给每只恐龙的编号，像学号一样，方便找到它

在 MySQL 里创建这个表：

-- 创建恐龙表
CREATE TABLE dinosaurs (
  id      INT          PRIMARY KEY AUTO_INCREMENT,
  name    VARCHAR(50),
  type    VARCHAR(50),
  age     INT
);

-- 解释一下：
-- VARCHAR(50) = 最多50个字的文本
-- INT = 整数（1, 2, 3...）
-- PRIMARY KEY = 主键，每行的唯一标识
-- AUTO_INCREMENT = 自动编号

4. SQL - 和数据库说话 语言

我们想对数据库做事情（查数据、加数据、改数据、删数据），就需要用一种「语言」来告诉 MySQL。

💬 SQL 是什么？

SQL（Structured Query Language，发音是 "S-Q-L" 或者 "sequel"）

它就是和 MySQL 说话的语言！

SQL 有几种基本的「动词」：

🔍
SELECT
查数据（看有什么）
➕
INSERT
加数据（添加新的）
✏️
UPDATE
改数据（修改旧的）
🗑️
DELETE
删数据（不要了）
SELECT = 看 | INSERT = 加 | UPDATE = 改 | DELETE = 删

5. 查数据 SELECT 最常用

SELECT 是最最常用的命令，用来查看表里的数据。

📌 基础用法

-- 查出所有数据（* 表示所有列）
SELECT * FROM dinosaurs;

结果：

idnametypeage
1霸王龙肉食恐龙25
2三角龙草食恐龙20
3翼龙飞行恐龙15

📌 只查某几列

-- 只看名字和种类，不看年龄
SELECT name, type FROM dinosaurs;
nametype
霸王龙肉食恐龙
三角龙草食恐龙
翼龙飞行恐龙
💡 想象一下

SELECT * = 打开整张纸看

SELECT name, type = 只看名字和种类那两列，像用手指遮住其他列

➕

6. 加数据 INSERT 增

INSERT 用来添加新数据到表里。

📌 插入一行数据

-- 给恐龙表添加一只新恐龙
INSERT INTO dinosaurs (name, type, age)
VALUES ('剑龙', '草食恐龙', 18);

现在表里有 4 只恐龙了：

idnametypeage
1霸王龙肉食恐龙25
2三角龙草食恐龙20
3翼龙飞行恐龙15
4剑龙草食恐龙18
🎮 像玩游戏

INSERT 就像「抓了一只新恐龙」，把它放进整理箱里！

id 会自动变成 4（因为我们设置了 AUTO_INCREMENT）

✏️

7. 改数据 UPDATE 改

UPDATE 用来修改已有的数据。

📌 修改数据

-- 把剑龙的年龄从18改成22
UPDATE dinosaurs
SET age = 22
WHERE name = '剑龙';

修改后的表：

idnametypeage
1霸王龙肉食恐龙25
2三角龙草食恐龙20
3翼龙飞行恐龙15
4剑龙草食恐龙22 ✅
⚠️ 重要提醒

WHERE 非常重要！

如果没有 WHERE name = '剑龙'，所有恐龙的年龄都会变成 22！

就像说「把所有恐龙都改名」，结果所有恐龙都变成一个名字了！😱

UPDATE 时一定要加 WHERE，否则改全部！
🗑️

8. 删数据 DELETE 删

DELETE 用来删除数据。

📌 删除数据

-- 删除翼龙
DELETE FROM dinosaurs
WHERE name = '翼龙';

删除后的表：

idnametypeage
1霸王龙肉食恐龙25
2三角龙草食恐龙20
4剑龙草食恐龙22
🚨 小心！

DELETE 删了就真的没了！不像电脑的回收站可以恢复！

没有 WHERE 的话，会把整张表的数据都删掉！

📌 清空整张表

-- 删除所有数据（危险！）
DELETE FROM dinosaurs;
🎯

9. 条件 WHERE 筛选

WHERE 就像一个过滤器，帮我们找出符合条件的数据。

📌 常用条件

-- 找年龄大于20的恐龙
SELECT * FROM dinosaurs
WHERE age > 20;
idnametypeage
1霸王龙肉食恐龙25
4剑龙草食恐龙22
-- 找草食恐龙
SELECT * FROM dinosaurs
WHERE type = '草食恐龙';
idnametypeage
2三角龙草食恐龙20
4剑龙草食恐龙22

📌 条件符号

符号意思例子
=等于age = 20
>大于age > 20
<小于age < 20
>=大于等于age >= 20
<=小于等于age <= 20
<>不等于type <> '草食'

📌 多个条件（AND / OR）

-- AND：两个条件都要满足
SELECT * FROM dinosaurs
WHERE age > 20 AND type = '草食恐龙';
-- 结果：只有剑龙（年龄22，又是草食）

-- OR：满足任意一个就行
SELECT * FROM dinosaurs
WHERE age < 20 OR name = '霸王龙';
-- 结果：三角龙（年龄20，但age不<20，所以这条不对？）
-- 等等... age=20 不小于 20，所以只有霸王龙

10. 索引是什么？ 进阶

索引是 MySQL 里一个很重要的概念。

📑 索引是什么？

想象一本书的目录！

如果没有目录，想找「MySQL 是什么」这一章，你得一页一页翻...

有了目录，直接翻到那一页，快多了！

索引就像书的目录，帮 MySQL 快速找到数据。

📌 创建索引

-- 给 name 列创建索引（像给书加目录）
CREATE INDEX idx_name ON dinosaurs(name);

-- 给常用的查找加索引
CREATE INDEX idx_type_age ON dinosaurs(type, age);

📌 有索引 vs 没索引

❌
没有索引
100万条数据 → 要翻100万次 😫
✅
有索引
100万条数据 → 翻20次搞定！😄
⚠️ 注意

索引不是越多越好！

就像书不能加太多便利贴，会变乱。

索引会占用额外空间，而且修改数据时也要更新索引，慢了。

只给经常查询的列加索引！
