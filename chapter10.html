第10章索引入门

📑 索引是什么？

索引是 MySQL 里一个很重要的概念。

想象一本书的目录！

如果没有目录，想找「MySQL 是什么」这一章，你得一页一页翻...

有了目录，直接翻到那一页，快多了！

索引就像书的目录，帮 MySQL 快速找到数据。

💻 创建索引

-- 给 name 列创建索引（像给书加目录）
CREATE INDEX idx_name ON dinosaurs(name);

-- 给常用的查找加索引
CREATE INDEX idx_type_age ON dinosaurs(type, age);

⚡ 有索引 vs 没索引

❌
没有索引
100万条数据 → 要翻100万次 😫
✅
有索引
100万条数据 → 翻20次搞定！😄

⚠️ 注意：索引不是越多越好！

就像书不能加太多便利贴，会变乱。

索引会占用额外空间，而且修改数据时也要更新索引，慢了。

只给经常查询的列加索引！

📑 索引 = 书的目录 = 快速查找的秘诀
