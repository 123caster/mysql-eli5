第3章表 - 数据的家

📊 表是什么？

在 MySQL 里，数据都放在表（Table）里。

想象一下Excel 表格！

  • 有行（横着的一条一条）
  • 有列（竖着的一栏一栏）

🦕 恐龙表示例

比如我们创建一个「恐龙表」：

id（编号）name（名字）type（种类）age（年龄）
1霸王龙肉食恐龙25
2三角龙草食恐龙20
3翼龙飞行恐龙15

每一行 = 一只恐龙的信息

每一列 = 恐龙的一个特点（名字、种类、年龄...）

id = 给每只恐龙的编号，像学号一样

💻 创建表的 SQL

-- 创建恐龙表
CREATE TABLE dinosaurs (
  id      INT          PRIMARY KEY AUTO_INCREMENT,
  name    VARCHAR(50),
  type    VARCHAR(50),
  age     INT
);

-- 解释一下：
-- VARCHAR(50) = 最多50个字的文本
-- INT = 整数（1, 2, 3...）
-- PRIMARY KEY = 主键，每行的唯一标识
-- AUTO_INCREMENT = 自动编号
📊 表 = 数据的「Excel 表格」
