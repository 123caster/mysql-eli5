第7章改数据 UPDATE

✏️ UPDATE 是什么？

UPDATE 用来修改已有的数据。

📌 修改数据

-- 把剑龙的年龄从18改成22
UPDATE dinosaurs
SET age = 22
WHERE name = '剑龙';

修改后的表：

idnametypeage
1霸王龙肉食恐龙25
2三角龙草食恐龙20
3翼龙飞行恐龙15
4剑龙草食恐龙22 ✅

⚠️ 重要提醒：WHERE 非常重要！

如果没有 WHERE name = '剑龙'，所有恐龙的年龄都会变成 22！

就像说「把所有恐龙都改名」，结果所有恐龙都变成一个名字了！😱

✏️ UPDATE 时一定要加 WHERE，否则改全部！
