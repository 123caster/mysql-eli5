📋 学习前提

  • ✅ 基础 SQL：SELECT / INSERT / UPDATE / DELETE
  • ✅ WHERE 条件、JOIN、GROUP BY、ORDER BY、LIMIT
  • ✅ 能使用 EXPLAIN 分析 SQL 执行计划
  • ✅ 了解基础索引概念：普通索引、唯一索引、主键索引
