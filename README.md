## 📖 内容概览

- 数据库是什么？
- MySQL 是什么？
- 表 - 数据的家
- SQL 基础语言
- SELECT 查数据
- INSERT 加数据
- UPDATE 改数据
- DELETE 删数据
- WHERE 条件筛选
- 索引入门

## 🎯 特色

- 🌈 可爱的视觉设计
- 📱 响应式布局，支持手机
- 🎈 简单易懂的语言
- 🦕 用恐龙举例，生动有趣
