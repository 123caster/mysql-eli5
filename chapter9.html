第9章条件 WHERE

🎯 WHERE 是什么？

WHERE 就像一个过滤器，帮我们找出符合条件的数据。

📌 常用条件

-- 找年龄大于20的恐龙
SELECT * FROM dinosaurs
WHERE age > 20;
idnametypeage
1霸王龙肉食恐龙25
4剑龙草食恐龙22

📌 条件符号

符号意思例子
=等于age = 20
>大于age > 20
<小于age < 20
>=大于等于age >= 20
<=小于等于age <= 20
<>不等于type <> '草食'

📌 多个条件（AND / OR）

-- AND：两个条件都要满足
SELECT * FROM dinosaurs
WHERE age > 20 AND type = '草食恐龙';
-- 结果：只有剑龙（年龄22，又是草食）

-- OR：满足任意一个就行
SELECT * FROM dinosaurs
WHERE age < 20 OR name = '霸王龙';
-- 结果：只有霸王龙
🎯 WHERE = 筛选条件 | AND = 两个都要 | OR = 满足一个
