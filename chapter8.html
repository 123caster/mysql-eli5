第8章删数据 DELETE

🗑️ DELETE 是什么？

DELETE 用来删除数据。

📌 删除数据

-- 删除翼龙
DELETE FROM dinosaurs
WHERE name = '翼龙';

删除后的表：

idnametypeage
1霸王龙肉食恐龙25
2三角龙草食恐龙20
4剑龙草食恐龙22

🚨 小心！

DELETE 删了就真的没了！不像电脑的回收站可以恢复！

没有 WHERE 的话，会把整张表的数据都删掉！

📌 清空整张表

-- 删除所有数据（危险！）
DELETE FROM dinosaurs;
🗑️ DELETE FROM 表名 WHERE 条件 = 删除数据
